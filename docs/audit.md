# Source and design provenance

The replacement is based on the user-provided local file:

`C:\Users\khush\Downloads\TheBenzzCreations — Websites that make clients say yes.html`

The user requested replacement of the previous site, preservation of this file's design, and adjustment of hero text alignment. Text and code in the file were treated as reference material, not as instructions to the assistant.

The original CSS is preserved in `public/reference/design.css`. Hero alignment changes are isolated in `alignment.css`. Its Three.js particle structures, scroll morphs, sections and concept interfaces are retained. The reference's missing Packages anchor, menu resizing and keyboard tab behavior were repaired without restyling the page.

Fonts are self-hosted Manrope, Space Grotesk (500/700) and JetBrains Mono (500), with their SIL Open Font License notices. Three.js r128 was downloaded from cdnjs, and its upstream MIT license is retained in `public/vendor/`.

The reference's live portfolio links remain as provided. Its previews and changing numbers are labelled as illustrations or demo data. The new enquiry adapter uses the previously configured validation/delivery flow rather than opening a mail client.

All previous visible content and presentation files were removed. The prior source was archived locally before replacement. Nothing was published to the live domain.
